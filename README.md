# 群晖AI识别 | 本地 AI 照片关键词写入工具（Vibe Coding）:)
本项目仅适用于Windows + NVIDIA CUDA，环境配置完成后可离线使用。

完整的配置、使用、恢复和故障处理说明请阅读 `使用手册.md`。

使用本地显卡运行，推荐显存至少16G否则模型可能无法成功加载。

本项目模型为`Qwen3-VL-8B-Instruct` 官方 `Q8_0` GGUF 模型，为照片生成中文描述关键词。
